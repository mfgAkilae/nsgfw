Translation engine worked examples

Prototype for Prototype: Translation engine worked examples (issue 22). Throwaway. Rule base in, NSG rules per Managed NSG out, with priorities, names, the Preview, Affected Zones and the write order.

Question. Does the Translation engine behave the way administrators expect? Each tab is a worked example that follows the decisions so far (ADR 0004 to 0018 and the ticket resolutions). Click the numbered steps in order; each step is a Version that is committed, or a Change set on top of the last Version. The ticks say where the output matches a decision. Use the buttons in the tables to move or disable Rules, switch Egress postures, commit, or fail a write, and watch the output change.

The engine (engine.js) is a pure module; this page only renders it. node run.mjs runs every example and its checks in the terminal.
